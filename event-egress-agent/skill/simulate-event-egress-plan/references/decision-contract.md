# 方案判断合同

## 固定案例能力门禁

门禁读取 `egress-policy.json`：

```text
24 分钟到达安全缓冲区比例 = 完成离场人数 / 合格参与人数
出口排队密度比 = 该出口未处理队列 / 该出口安全排队容量
最高排队密度比 = 所有轮次、所有出口排队密度比的最大值
溢出轮次 = 最高出口排队密度比大于 1 的轮次数
```

四道条件同时满足，候选才可签发：

1. 24 分钟到达安全缓冲区比例达到策略线；
2. 最高排队密度比不超过策略线；
3. 溢出轮次不超过策略线；
4. 系统没有执行现实封路、运力调度、生产写入或公众发布。

这些是固定案例的校准门禁，不是现实活动的安全认证，也不是公开承诺。现实阈值必须由场馆、交通、安保和属地责任人依据法规与现场条件重新校准。

## 产品指标合同

北极星使用“合格大型活动散场任务 30 分钟内安全方案签发率”：

```text
分子 = 输入完整后 30 分钟内，至少一个候选同时通过完成率、密度、事件与权限门禁，并由具名责任人签发的任务数
分母 = 观察窗内所有达到输入完整事件的合格散场任务数
```

不能删除第一次失败、中途未签发或没有候选通过的任务。重复任务和经审计确认的采集技术故障可以剔除。首次输入完整率与输入到首次候选用时作为护栏，防止通过拒收复杂任务改善北极星。
