# 输入合同

一次推演必须同时具有以下对象：

- `task_type`：只能是 `large_event_egress_simulation`；
- `event`：活动名称、合格参与人数、单轮分钟数、最大轮次；
- `exits`：出口 ID、单轮容量、安全排队容量和地图坐标；
- `groups`：客群 ID、人数、每轮释放上限和起点；
- `events`：事件起止轮次、受影响出口和容量倍率；
- `candidates`：至少三个候选，每个候选包含客群出口偏好和重规划策略。

客群人数之和必须等于活动合格参与人数。出口容量必须为非负整数；事件容量倍率必须在 0 到 1 之间；同一客群在一个候选中至少有一个出口偏好。

缺少必需字段时停止。不要从活动名称、地图截图或常识中猜人数与容量。
