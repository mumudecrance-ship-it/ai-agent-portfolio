# 04 节点方案 · 追加评价引导文案

> 生产形态按周批量执行（迭代逐条首评）；演示环境按单条首评触发（迭代外层由调度承担），节点逻辑一致。

## 节点表

| 节点id | 节点名 | 平台节点类型 | 对应S3步骤 | 配置要点 |
|---|---|---|---|---|
| start | 开始 | start | — | 入参：product_id、review_text、star、has_followup |
| detail | 商品信息获取 | http_request | 3 | 商品信息中心 /mock/item-center/detail；与文字链并行 |
| batch | 增量首评拉取（生产态） | http_request + iteration | 1 | 评价查询服务批量拉取后逐条迭代；演示态由 start 直接携带单条 |
| filt | 候选过滤 | code | 2 | 已追加评价/星级≤2/字数<10 判定，输出 eligible、low_info |
| br1 | 是否进引导 | if_else | 2 | eligible==yes；false→end_skip |
| br2 | 是否个性化分支 | if_else | 2 | low_info==no；false→tpl_general |
| extract | 首评关键点提取 | llm | 4 | 输出 JSON{has_point,point,type}；商品信息作变量 |
| br3 | 是否有有效关键点 | if_else | 4 | has_point==1；false→tpl_general（拿不准转模板，三态出口) |
| angle | 追加评价角度映射 | code | 5 | type→angle 映射表（效果衰减/耐用性/适配场景/通用） |
| gen | 追加评价引导文案生成 | llm | 6 | 输出 JSON{guide_text,angle,self_check}；含红线自检重写 |
| tpl_general | 通用引导文案 | template_transform | 2/4兜底 | 角度库通用文案拼装，零 LLM 开销 |
| agg | 文案聚合 | variable_aggregator | 6 | first_not_null[gen 产物, tpl_general 产物] |
| sens | 敏感词检测 | http_request | 7 |  /mock/svc/sensitive-words，对出站文案执行 |
| br4 | 是否命中敏感词 | if_else | 7 | hit==False→pool；true→end_drop |
| pool | 汇总审核池条目 | code | 8 | 组装 user/review 引用+guide_text+angle |
| end_ok | 结束-入运营审核池 | end | 9 | 人审出口：输出 need_review=true 的审核池条目 |
| end_skip | 结束-不打扰 | end | 2 | 输出 skip 原因 |
| end_drop | 结束-安全拦截 | end | 7 | 输出拦截记录（回流反例） |

## 分支句柄连线

- br1：true→br2 / false→end_skip
- br2：true→extract / false→tpl_general
- br3：true→angle / false→tpl_general
- br4：true→end_drop / false→pool
- 并行：start→detail 与 start→filt 双出边，在 extract 前汇聚（extract 同时引用两路）

## 出处核对

平台节点：start/end/code/if_else/llm/template_transform/variable_aggregator/http_request/iteration——均见 `platform-nodes/`。
业务能力：商品信息中心、评价查询服务、敏感词——均见 `domain-nodes/`（敏感词用于工作流自产文本出站，符合图像文本基础能力使用口径）。
