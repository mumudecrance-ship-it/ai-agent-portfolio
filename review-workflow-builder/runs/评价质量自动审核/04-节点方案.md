# 04 节点方案 · 评价质量自动审核

## 节点表

| 节点id | 节点名 | 平台节点类型 | 对应S3步骤 | 配置要点 |
|---|---|---|---|---|
| start | 开始 | start | — | 入参：review_text/image_urls/star/user_level/product_id |
| detail | 商品信息获取 | http_request | 6-10供参 | 商品信息中心，与判定链并行 |
| form | 形式判断（带图/字数） | code | 1/2 | 输出 has_img、gt60 |
| br_img | 是否带图 | if_else | 1 | false→图片链剪枝 |
| same_img | 同图识别 | http_request | 3 | 0/1/2 |
| ai_img | AI生图识别 | http_request | 4 | 0/1；商品无标注跳过口径由接口返回 |
| irr_img | 无关图识别 | http_request | 5 | 0/1/2 |
| br_len | 字数分流 | if_else | 2 | true→judge_hi / false→judge_lo |
| judge_hi | 大于60字质量初筛 | llm | 6 | 输出 JSON{verdict,reason,confidence}；商品信息变量 |
| judge_lo | 小于60字质量初筛 | llm | 7 | 同上，只判普通/低质量 |
| agg_judge | 初筛聚合 | variable_aggregator | 6/7 | first_not_null 双分支汇合 |
| br_q | 初筛是否疑低质量 | if_else | 8/11分流 | verdict==1→低质量细分；0→高质量深校链 |
| rag_tpl | 检索本商品历史高质量评价 | knowledge_retrieval | 8 | product_id 限定，top_k 20 |
| tpl_chk | 套模板校验 | llm | 8 | 参照检索结果，输出 is_template |
| precision | 商品价值描述精准度 | llm | 9 | 0/1 |
| after_use | 是否使用后评价 | llm | 10 | 0/1 |
| low_type | 低质量类型细分 | llm | 11 | 六类枚举（广告引流/极端情绪需案例参照，生产态挂案例库RAG） |
| final | 综合判断 | code | 12 | 交集规则：精准度/使用后任一为1→结合图片结果取交集；同图=2直接打标；疑似态(任一接口=1或低置信)→转审 |
| end_ok | 结束-输出质量标签 | end | 12 | 标签+类型+need_review 转审标记 |

共 19 节点。生产态另有旁路：复审结论回流 prompt 长期记忆（客服复审工作台承接，S2 已标缺口）。

## 分支句柄连线

- br_img：true→same_img/ai_img/irr_img（三接口并行）/ false→图片链剪枝
- br_len：true→judge_hi / false→judge_lo，agg_judge 汇合
- br_q：true→low_type / false→rag_tpl→tpl_chk 与 precision、after_use 并行
- 汇聚：final 收图片三接口+agg_judge+tpl_chk+precision+after_use+low_type（被剪枝路径为 null，规则内处理）

## 出处核对
平台节点 9 类均见 `platform-nodes/`；图像识别三接口/商品信息中心/评价检索均见 `domain-nodes/`；低质量细分的案例参照生产态依赖案例沉淀库（domain-nodes 已述）。
