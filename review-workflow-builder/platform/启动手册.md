# FlowBench 平台启动手册

评价域工作流平台的本地运行版（本地演示）。跑通它，就能把工作流的「导入 → 发布 → 试运行 → 逐节点看结果」完整走一遍。

## 1. 前置要求

- Python 3.8 及以上（Windows / Mac 通用），**无需安装任何第三方库**
- 检查方式：终端（Windows 用 cmd 或 PowerShell）执行 `python --version` 或 `python3 --version`
- 没有 Python：去 [python.org/downloads](https://www.python.org/downloads/) 下载安装。**Windows 安装时务必勾选 "Add Python to PATH"**

## 2. 启动（两步）

```
cd platform
python platform.py        # Mac 上若报错用 python3
```

看到 `FlowBench 工作流平台（本地演示版）已启动` 即成功。
浏览器打开 **http://127.0.0.1:8787** 进入画布。

Windows 也可直接双击 `demo-scripts/start.bat`；Mac 可执行 `bash demo-scripts/start.sh`。

## 3. 第一次跑通（3 分钟）

1. 画布页点右上角「导入定义」，把 `demo-scripts/demo_质量管控迷你.json` 的内容整体粘贴进去，点导入
2. 点右上角「发布」
3. 右侧「试运行」面板已预填示例输入，点「▶ 运行」
4. 看结果：画布上节点变绿（成功）；右侧有最终输出和逐节点流水，点任意节点看它的输入输出

试一条低质量评价：把输入里的 `review_text` 换成
`宝贝收到了，质量很好，卖家服务态度好，物流很快，包装严实，值得购买，下次还来。这条评价故意凑到六十个字以上以便走高质量判定分支流程。`，`image_urls` 换成 `["img/tpl-same-1.jpg"]`，再运行——输出 `quality` 变为「低质量」。

## 4. 演示失败分支（面试常问：出错了怎么定位）

导入的定义里，给「同图识别」节点的 `body` 加一行 `"__inject__": "500"`，重新导入发布运行——该节点红标，右侧给出节点级报错，这就是运行结果回读能力。

## 5. 自动化验证（可选）

平台开着的状态下：

```
python demo-scripts/smoke_test.py
```

全绿说明导入/发布/运行/回读四段链路 + 错误注入全部可用。

## 6. 常见报错排查

| 现象 | 原因与处理 |
|---|---|
| `python 不是内部或外部命令` | Windows 没勾 Add to PATH，重装 Python 勾上；或用 `py platform.py` |
| `Address already in use` | 8787 端口被占：`python platform.py 8788`（换端口后浏览器地址同步换） |
| 页面空白 / canvas.html 缺失 | `platform.py` 和 `canvas.html` 必须在同一目录，别单独拷走 |
| 中文乱码（Windows cmd） | 执行 `chcp 65001` 后再启动 |
| LLM 节点输出是「演示模式输出·未命中种子规则」 | 正常兜底。想要有意义输出：在 `seed-data/llm_demo_outputs.json` 加匹配规则，或在 `seed-data/platform_config.json` 填 API key 切真模型 |

## 7. 目录说明

```
platform/
├── platform.py          平台本体（HTTP 服务）
├── canvas.html          画布（可视化工作流）
├── 平台定义文档.md       工作流定义规范（节点 schema 权威来源）
├── seed-data/           种子数据（商品/评价样本、LLM演示输出、平台配置）
├── demo-scripts/        一键脚本（启动、示例定义、冒烟测试）
└── 启动手册.md          本文件
```
