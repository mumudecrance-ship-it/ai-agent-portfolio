# 知识检索节点（knowledge_retrieval）

## 能力
- 对挂载数据集做检索，`config`: `query`（可含槽位）、`top_k`、`product_id`（限定检索范围）
- 输出 `result`（命中列表，含 score）、`count`

## 真实 DSL 片段
```json
{"id": "rag_tpl", "type": "knowledge_retrieval", "title": "检索本商品历史高质量评价",
 "config": {"query": "{{#inputs.review_text#}}", "top_k": 20, "product_id": "{{#inputs.product_id#}}"}}
```

## 评价域使用要点
- 评价语料按句分片、窗口为上下句（总结项目口径）；每商品单独建库可省元数据过滤
- 典型用法①套模板校验：把本商品历史 >60 字评价作为参照喂给下游 LLM（质量管控功能点8）
- 典型用法②卖点找评价：逐卖点检索相关评价句（总结工作流）；rerank 阈值口径 0.7/0.8 由算法侧负责
- 检索结果给 LLM 时取 top_k 截断，防上下文超长——这也是开销控制点
