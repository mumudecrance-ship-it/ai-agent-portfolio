# 开始 / 结束节点（start / end）

## 能力
- `start`：工作流唯一入口。输入变量由定义顶层 `variables` 声明（name/type/required/example），运行时经 `{{#inputs.变量名#}}` 引用。
- `end`：出口，可多个（不同分支各自收尾）。`config.outputs` 把上游字段映射为最终输出。

## 真实 DSL 片段
```json
{"id": "start", "type": "start", "title": "开始"}
{"id": "end", "type": "end", "title": "结束",
 "config": {"outputs": {"quality": "{{#final.quality#}}", "need_human": "{{#final.need_human#}}"}}}
```

## 评价域使用要点
- 评价类工作流的 start 常规入参：评价文本、图片URL列表、商品ID、用户等级（评价官/PLUS/普通）
- 拿不准转人审的场景：end 输出必须带 `need_human` 一类的转审标记字段——人审兜底是方法论第⑥条
