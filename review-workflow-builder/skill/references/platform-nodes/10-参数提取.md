# 参数提取节点（parameter_extractor）

## 能力
- `config`: `input`（文本引用）、`parameters`: [{name, type, pattern?, max_len?}]
- 从非结构化文本提取结构化参数；有 pattern 走正则，type=number 提取数值

## 真实 DSL 片段
```json
{"id": "extract", "type": "parameter_extractor", "title": "提取商品ID",
 "config": {"input": "{{#inputs.query_text#}}",
   "parameters": [{"name": "product_id", "type": "string", "pattern": "\\b(100\\d{8,})\\b"}]}}
```

## 评价域使用要点
- 评价文案"先进正则，后进 A4"的前置正则过滤即此形态——能正则命中的不进 LLM（开销与方法论第①条）
- 提取失败输出 null，下游必须有 empty 分支兜底
