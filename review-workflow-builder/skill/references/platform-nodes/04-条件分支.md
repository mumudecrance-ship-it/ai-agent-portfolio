# 条件分支节点（if_else）

## 能力
- `config.conditions`: [{left, op, right}]，`logic`: and/or；op ∈ ==,!=,contains,not contains,>,<,>=,<=,empty,not empty
- 分支句柄固定为 `true` / `false`，出边必须带 `source_handle`

## 真实 DSL 片段
```json
{"id": "branch", "type": "if_else", "title": "字数分支",
 "config": {"conditions": [{"left": "{{#len_check.gt60#}}", "op": "==", "right": "yes"}]}}
{"source": "branch", "target": "judge_hi", "source_handle": "true"}
{"source": "branch", "target": "judge_lo", "source_handle": "false"}
```

## 评价域使用要点
- 能传统判断的绝不进 LLM（方法论第①条）：字数、是否带图、接口返回码分流全用它
- 三态接口结果（0/1/2）需要三路时用问题分类器或两级 if_else
