# 问题分类器节点（question_classifier）

## 能力
- `config`: `input`（待分类文本引用）、`classes`: [{id, name, keywords, default?}]
- 输出 `class` / `class_name`；分支句柄 = 命中的 class id，每类一条出边

## 真实 DSL 片段
```json
{"id": "low_type", "type": "question_classifier", "title": "低质量类型分流",
 "config": {"input": "{{#judge.json.reason#}}",
   "classes": [
     {"id": "ad", "name": "广告引流", "keywords": ["引流", "领券", "平台"]},
     {"id": "emotion", "name": "极端情绪", "keywords": ["辱骂", "泄愤"]},
     {"id": "offtopic", "name": "跑题", "keywords": ["无关", "跑题"]},
     {"id": "other", "name": "其他", "keywords": [], "default": true}]}}
```

## 评价域使用要点
- 质量管控工作流低质量六分支（广告/情绪/跑题/水字/拼写/客观差评）即此形态
- 必须设 default 类兜底，否则漏分类断流
- 分类粒度粗、判据浅时用它；判据需要深度语义的每类单开 LLM 判定节点
