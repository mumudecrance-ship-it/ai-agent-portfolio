# 变量聚合节点（variable_aggregator）

## 能力
- `config`: `variables`: [引用列表]、`strategy`: first_not_null / merge_list
- 输出 `output`

## 真实 DSL 片段
```json
{"id": "agg", "type": "variable_aggregator", "title": "判定聚合",
 "config": {"strategy": "first_not_null",
   "variables": ["{{#judge_hi.json#}}", "{{#judge_lo.json#}}"]}}
```

## 评价域使用要点
- 互斥分支（双主 prompt 分流）汇合处的标准做法：被剪枝分支的引用为 null，first_not_null 取到实际执行的那路
- 多路结果合并成列表（如多个细分判定）用 merge_list
- 需要带逻辑的合并（交集/加权）不要用它，换 code 节点
