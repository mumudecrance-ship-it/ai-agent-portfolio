# 模板转换节点（template_transform）

## 能力
- `config.template`: 含槽位的文本模板，输出 `output`（拼装后的字符串）
- 用于把多个上游字段拼装成下游 prompt 的输入块、或整理最终输出格式

## 真实 DSL 片段
```json
{"id": "pack", "type": "template_transform", "title": "拼装亮点判定入参",
 "config": {"template": "词云TOP10：{{#wordcloud.body.top10#}}\n已有标签：{{#detail.body.product.sellpoints#}}\n待判定评价：{{#inputs.review_text#}}"}}
```

## 评价域使用要点
- 亮点工作流"词云高频词+已有标签+新发现亮点作为 prompt 输入"的拼装层即此形态
- 纯字符串拼装用它（零开销）；需要计算/过滤再拼的用 code
