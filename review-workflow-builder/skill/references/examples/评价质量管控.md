# 复盘 · 评价质量管控

> 盲测判分完成后按约入库（见 README 入库状态）。

## 业务问题
恶意与低质量评价侵蚀评价区信任：规则+算法+人工模式下，抽样精校口径的低质量检出率约五成，高质量评价识别动力不足。目标：自动判定高/普通/低质量并细分类型，拿不准转客服复审。

## 依赖能力
评价查询服务（已过公司级敏感过滤的新增评价）、商品信息中心（商品信息变量）、图像识别三接口（同图/AI生图/无关图，0/1/2 三态口径）、本商品历史高质量评价知识库（套模板参照）、客服复审工作台（转审+回流）。

## 节点结构（平台节点口径，18 功能点）
形式判断（带图/字数，传统）→ 字数分流双主 prompt（>60 判高低 / ≤60 判普低，商品信息作变量）‖ 图片三接口并行 → 高质量分支：套模板校验（挂历史评价知识库）→ 价值描述精准度 → 使用后评价；低质量分支：分类主 prompt → 六类细分（广告引流/极端情绪需 RAG，客观差评无过分词汇放行）→ 综合判断（传统，交集规则：精准度/使用后任一为是再看图片结果取交集）→ 拿不准转客服复审，复审通过回流对应 prompt 长期记忆。

## 方法论要点
- 起点不必是主 prompt：工作流不涉及人的直接对话（与对话型应用的本质差异）
- 双主 prompt 按字数分流（互斥只走一路，开销与任务单一性双收）
- 三态接口的"疑似"一律人审；同图=2 直接打标无需复审
- 复审回流长期记忆：人审结论变成 prompt 资产（沉淀旁路）
