# 商品信息中心

> http_request 节点调用。mock 地址 `POST /mock/item-center/detail`。

| 项 | 说明 |
|---|---|
| 入参 | `{product_id}` |
| 返回 | `{product: {product_id, title, category, sellpoints[], params{}}}` |
| 不存在 | 404，节点失败 |

## 使用口径

- 一切"判定评价与商品关系"的 LLM 节点都需要它供商品信息变量（标题/卖点/参数）
- 商品主数据概念：不同商家同一标品映射同一主数据。**亮点场景取主数据全部评价，问题场景只取本人名下商品**——数据范围是方案必答项
- 商详页图片 URL 也从这里取，供 OCR 提卖点链路
