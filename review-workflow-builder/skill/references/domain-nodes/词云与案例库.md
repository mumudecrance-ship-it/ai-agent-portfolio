# 词云服务 / 案例沉淀库

## 词云服务

| 项 | 说明 |
|---|---|
| 能力 | 按商品返回正向/负向高频词 TOP N（既有算法系统，非 AI） |
| 演示环境 | 未内置独立 mock；方案中作为已有能力引用，演示时以静态入参代替 |
| 口径 | 正负向可切分；亮点场景取 TOP10 正向高频词作"已知亮点"排除项——新亮点不太可能在 TOP10 里 |

## 案例沉淀库（prompt 长期记忆 / 亮点沉淀）

| 项 | 说明 |
|---|---|
| 能力 | 两类沉淀：①复审通过的识别案例回流进对应 prompt 的长期记忆（质量管控）②未审核亮点预入库供跳过判断（亮点） |
| 演示环境 | 未内置独立 mock；方案中作为机制设计呈现，落地由开发实现存储 |
| 口径 | 沉淀跳过是核心降开销机制：评价只含已识别亮点时跳过后续 prompt；对应语句打标后再次执行可剔除 |

## 缺口标注规则

方案依赖了上述两类能力之外、且 domain-nodes 其他文件也没有的能力时，一律在依赖清单标 `缺失需人补`，注明需要哪个团队提供什么接口——**不得假装能力存在**。
