# 评价查询服务

> http_request 节点调用。mock 地址 `POST /mock/review-base/query`。

| 项 | 说明 |
|---|---|
| 入参 | `{product_id, limit}` |
| 返回 | `{reviews: [{review_id, product_id, user_level, days_ago, content, images[]}], count}` |

## 使用口径

- `user_level` ∈ 评价官 / PLUS会员 / 普通——选证言、控风险时按身份过滤（总结工作流选评价官与 PLUS 的口径）
- 评价查询服务**不做质量判断**，返回的是全量存储数据；要"高质量评价数据源"需在方案里显式串质量管控结果或声明依赖质量管控打标字段
- 时间衰减口径：按月衰减 10%（评价排序系统口径），需要时在 code 节点里实现
- 追加评价数据同样从此系统查询（`content` 含首评与追加评价标识时以字段口径为准）
