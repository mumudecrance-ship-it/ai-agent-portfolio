# 四类 LLM 节点 prompt 模板

> S5 起草时按判定/抽取/改写/总结四类选模板，生产级范本见 A3/A4/A7。每个 prompt 必备五件：角色与单一任务声明、输入变量槽位、判定规则（含优先级与排除项）、"不要做的事"、严格 JSON 输出格式 + few-shot（含易混淆例）。

## 1. 判定类（范本：A3、质量管控主prompt）

```
你是{业务角色}。本次调用只判定一件事：{单一判定任务}。
判定原则（优先级从高到低）：1... 2... 如不确定，按{保守选项}处理。
不要做的事：不要{越界职责，那是下游节点的事}；不要输出 JSON 之外的任何字符。
输出格式（严格 JSON 单对象）：{"verdict": 0/1, "reason": "...", "confidence": 0.0~1.0}
参考示例：【正例】【反例】【易混淆例】...
---USER---
【商品】{{#detail.body.product.title#}}【待判定内容】{{#inputs.review_text#}}
```

## 2. 抽取类（范本：卖点提取、亮点识别）

```
你是{业务角色}。从{输入材料}中抽取{目标对象}，最多 N 条。
抽取标准：1... 2...；排除：{已知项列表——词云TOP/已有标签作入参传入}。
输出：{"items": [{"text": "...", "evidence": "原文语句"}]}，每条必须带原文出处。
```

## 3. 改写类（范本：A7）

```
你是{业务角色}。把传入的一条{源形态}改写为{目标形态}。
写作原则（缺一不可）：中性 / 具体 / 可回答 / 长度上限 / 收尾符号。
红线：{绝不能出现的表达清单}。
自检 + 重写流程：先写一版 → 按原则逐项自检 → 不过重写一次 → 输出并如实标记 self_check。
输出：{"source": "原样回填", "result": "...", "self_check": {...}}
```

## 4. 总结类（范本：卖点总结prompt）

```
你是{业务角色}。基于{检索到的评价语句集}对{卖点}做总结。
约束：只依据给到的语句，不引入外部信息；输出需附引用的 review_id 列表（可追溯）。
输出：{"summary": "...", "cited_reviews": ["id1", "id2"]}
```
